# Roadmap

✅ works · 🗓️ planned · 💡 idea

Update this file in the same change as the work it describes.

## Works ✅

- **Game flow:** lobbies for any queue, Practice Tool, role preferences, ready check, queue and cancel, leave, dodge.
- **Champion select:** hover, lock, bans, enemy team and bans, pick-order and role swaps, trades, spells, runes, skins
  and chromas, ARAM bench and rerolls, anonymous draft chat.
- **Auto pick and ban:** presets per queue and role, with a cancel before the auto lock. Auto Accept for the ready check.
- **Social:** chat, friends and presence, friend requests, lobby invites.
- **Profile:** rank, mastery, form, roles, match history and game details. Teammates' profiles and Riot ID search.
- **Live game:** game clock, scoreboard, objective and buff timers, events.
- **Post-game:** result, LP and mastery, Play Again.
- **Alerts:** Web Push with per-phone choices, and the client's own sounds and music.
- **Phone app:** iOS-style design system, light and dark, large text, Increase Contrast, Reduce Motion, VoiceOver, demo
  scenarios for every screen.
- **PC app:** one `LeagueRemote.exe` with a tray menu: HTTPS with a local certificate authority, pairing by QR, code or
  link, several phones, Start with Windows, Allow on Private Networks, rolling log files, optional `settings.json`.

## Next 🗓️

- Code signing for the exe.
- Check the League client's certificate against Riot's chain instead of by host.
- End-to-end encryption between phone and PC.
- Trends over more than the last 20 games.
- Chroma preview art in the skin picker.

## Ideas 💡

- Power spikes and item gold difference in the live game view.
- Reaching the PC away from home, for example through a VPN. Not supported today.
- Translations.
- Push for more events.
