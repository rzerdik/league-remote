# League Remote web app

The phone app: Vue 3, Vite and TypeScript. It talks to the connector over SignalR (`/hub`) and is embedded in the exe
when the connector is built. Design rules: [CLAUDE.md](CLAUDE.md). Code standards:
[../docs/standards/typescript-vue.md](../docs/standards/typescript-vue.md).

```sh
npm ci
npm run dev -- --port 5179 --strictPort    # http://localhost:5179, also on your LAN
npm run build                              # tokens, vue-tsc type-check, vite build -> dist/
npm run preview                            # serve dist/ (the service worker only runs in builds)
```

Open `/?demo=<scenario>` for any screen with fake data and no PC. The scenarios are in `src/dev/demo/index.ts`.
Without `?demo=`, the dev server proxies `/hub` and `/client-sounds` to the connector on `localhost:5080`
(`LR_DEV_CONNECTOR` points the proxy elsewhere).

## Pairing

The tray QR code is a link `https://<pc-ip>:5443/?pair=123456`. Three ways to pair, all calling `RedeemPairingCode`:

1. Scan the QR with the phone camera. The app reads `?pair=`, removes it from the address and pairs.
2. **Scan QR code** inside the app. It needs HTTPS.
3. Type the 6 digits, or paste the link.

## Notes

- `src/contracts/` mirrors `src/LeagueRemote.Contracts`.
- Champion, spell and item images come from Riot's Data Dragon and are cached by `public/sw.js`.
- Icons are generated by `node scripts/gen-icons.mjs`. They are original artwork.
